## 🎯 Key Layout Principles

1. **Horizontal Flow:** Left-to-right information flow
2. **Category Grouping:** Related categories positioned near each other
3. **Visual Hierarchy:** Top stripe color coding, thick borders
4. **Information Density:** 4-column grids maximize space usage
5. **Nested Structure:** Field Tools nested within Voter Contact
6. **Sidebar:** Movement-Wide acts as vertical sidebar
7. **Zigzag Arrows:** Grid-based arrow paths with 50% break points
