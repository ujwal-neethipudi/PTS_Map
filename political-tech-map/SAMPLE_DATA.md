## How to Use This Template

### Method 1: Direct Paste to Google Sheets

1. Copy the entire CSV block above
2. Go to Google Sheets
3. Create a new spreadsheet
4. Paste into cell A1
5. Data → Split text to columns (if needed)

### Method 2: Import CSV

1. Copy the CSV data
2. Save as `political-tech-data.csv`
3. In Google Sheets: File → Import
4. Upload the CSV file
5. Choose "Replace current sheet"

### Method 3: Download Template

Download the pre-filled template:

## Column Descriptions

| Column | Required | Description | Example |
|--------|----------|-------------|---------|
| **Category** | Yes | Main grouping | "Messaging & Media" |
| **Subcategory** | No | Sub-grouping within category | "Creative Asset Development" |
| **Entity Name** | Yes | Company/tool name (displays if no logo) | "Treefly" |
| **Logo URL** | No | Direct image link | "https://logo.clearbit.com/treefly.com" |
| **Website URL** | No | Company website (clickable) | "https://treefly.com" |
| **Linked Category** | No | Creates arrow to another category | "Paid Media" |
| **Relevance Flag** | Yes | "Y" = show, "N" = hide | "Y" |

## Notes About This Template

1. **Clearbit Logo API**: Uses `https://logo.clearbit.com/{domain}` for automatic logos
   - Free to use
   - High quality
   - Auto-updated
   - Fallback to entity name if logo fails

2. **Duplicate Companies**: Some companies (like PDI, ActBlue) appear in multiple categories
   - This is intentional and shows their multi-purpose nature
   - Each row is independent

3. **Arrow Connections**: Currently set up:
   - Messaging & Media → Paid Media
   - Paid Media → Owned Media
   - Voter Engagement → Volunteer & Activist Mobilization
   - Fundraising → Movement-Wide

4. **Sample Data**: Contains ~100 rows
   - Add more rows following the same pattern
   - Keep category names consistent
   - Use "Y" for Relevance Flag to show

```csv

```
This creates an arrow from Category A → Category B

## Logo Sources

If Clearbit doesn't have a logo, try:

1. **Company Website**
   - Look for "Press" or "Media Kit" pages
   - Download logo (prefer SVG or PNG)
   - Upload to image host (Imgur, Cloudinary, etc.)

2. **Logo Aggregators**
   - Brandfetch: https://brandfetch.com
   - Wikimedia Commons
   - Company social profiles

3. **Create Placeholder**
   - Use first letter: https://ui-avatars.com/api/?name=Company
   - Example: `https://ui-avatars.com/api/?name=Treefly&background=1e3a8a&color=fff`

## Testing Your Sheet

Before connecting to the app:

1. ✅ Check all column headers match exactly
2. ✅ Ensure Relevance Flag is "Y" or "N" (not yes/no)
3. ✅ Verify category names are consistent
4. ✅ Test logo URLs load in browser
5. ✅ Check website URLs are complete (include https://)
6. ✅ Make sheet public or enable API access

## Advanced: Formulas

### Auto-generate Clearbit logos:

In Google Sheets, use:
```
=IF(E2<>"", CONCATENATE("https://logo.clearbit.com/", REGEXEXTRACT(E2, "https?://([^/]+)")), "")
```

This extracts domain from Website URL and creates Clearbit logo URL.

### Count entities per category:

```
=COUNTIF(A:A, "Messaging & Media")
```
